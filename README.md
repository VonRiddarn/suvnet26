# Suvnet 26

This is my school dump folder.  
A centralized place where I publish finished excercises for critique or inspiration.

## Why is it so whack?

The repo is a mono-repo containing more than one project.  
Each project may contain a local gitignore file or README.

Directories are loosely structured around the curriculum.

I've set it up this way to keep my repository count low whilst still sharing my code openly.

## How to run a program

Make sure your _current working directory_ is set to the sub-directory containing the project before execution.  
Most projects are as simple as `dotnet run`. Other projects may contain a local README.
